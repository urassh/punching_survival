# 射撃アニメーション統合ガイド

Blenderで作成した銃を撃つモーションをUnityに統合する手順です。

## 1. Blenderアニメーションのインポート

### 1.1 FBXファイルのインポート設定
1. Blenderで作成した射撃アニメーション付きFBXファイルを `Assets/Player/` フォルダにドラッグ&ドロップ
2. インポートしたFBXを選択し、Inspectorで以下を確認：
   - **Rig**タブ → Animation Type: `Humanoid` (または既存モデルと同じ設定)
   - **Animation**タブ → Import Animation: `チェックON`
   - アニメーションクリップが正しくインポートされていることを確認

### 1.2 アニメーションクリップの抽出
1. インポートしたFBXの▶を展開
2. 射撃アニメーションクリップ（例: `Shoot`）を探す
3. そのクリップを選択してインスペクタで設定を確認
   - Loop Time: `OFF`（射撃は1回だけ再生）
   - Loop Pose: `OFF`

## 2. Animator Controllerの設定

### 2.1 Parameterの追加
1. `Assets/Player/PlayerAnimator.controller` を開く
2. **Parameters**タブで `+` ボタンをクリック
3. タイプ: `Trigger` を選択
4. 名前: `Shoot` と入力

### 2.2 Stateの作成
1. Animator ウィンドウで右クリック → `Create State` → `Empty`
2. 新しいステートの名前を `Shoot` に変更
3. ステートを選択し、Inspectorの **Motion** に射撃アニメーションクリップをドラッグ

### 2.3 Transitionの設定

#### Any State → Shoot
1. `Any State` を右クリック → `Make Transition`
2. `Shoot` ステートに接続
3. トランジションを選択し、Inspectorで設定：
   - **Conditions**: `+` → `Shoot`
   - **Has Exit Time**: `OFF`
   - **Transition Duration**: `0.1` (素早く遷移)
   - **Interruption Source**: `Current State`

#### Shoot → Idle (または他の基本ステート)
1. `Shoot` ステートを右クリック → `Make Transition`
2. `Idle` ステート（または歩きステート）に接続
3. トランジションを選択し、Inspectorで設定：
   - **Has Exit Time**: `ON`
   - **Exit Time**: `0.95` (アニメーションがほぼ終わってから遷移)
   - **Transition Duration**: `0.1`

## 3. プレイヤープレハブの設定

### 3.1 基本設定（既存のBulletSpawnerを使う場合）
1. プレイヤープレハブを開く
2. `BulletSpawner` コンポーネントがアタッチされていることを確認
3. `Shoot Trigger Name` フィールドを `Shoot` に設定（Animatorで設定した名前と一致させる）

### 3.2 ネットワーク同期版を使う場合（推奨）
1. プレイヤープレハブを開く
2. 既存の `BulletSpawner` コンポーネントを削除（または無効化）
3. `Add Component` → `NetworkedBulletSpawner` を追加
4. `NetworkMecanimAnimator` コンポーネントを追加（まだなければ）
5. 設定：
   - **NetworkedBulletSpawner**:
     - Bullet Prefab: 弾丸のプレハブを割り当て
     - Fire Point: 銃口のTransformを割り当て
     - Shoot Trigger Name: `Shoot`
   - **NetworkMecanimAnimator**:
     - Animator: PlayerのAnimatorコンポーネントを割り当て
     - Sync Settings: 必要に応じて設定（デフォルトでOK）

## 4. アニメーションイベント（オプション）

射撃アニメーションの特定フレームで弾を発射したい場合：

### 4.1 Animation Eventの追加
1. 射撃アニメーションクリップを選択
2. Animationウィンドウで開く（Window → Animation → Animation）
3. 弾を発射したいフレームに `Animation Event` を追加
4. イベント関数名を設定（例: `OnShootFrame`）

### 4.2 スクリプトの修正
`NetworkedBulletSpawner.cs` に以下を追加：

```csharp
// アニメーションイベントから呼ばれる（オプション）
public void OnShootFrame()
{
    if (HasInputAuthority)
    {
        Debug.Log("Animation Event: Shoot frame reached!");
        // 必要に応じて追加処理
    }
}
```

## 5. テスト

1. Unityエディタでプレイモードに入る
2. ジェスチャーまたはUIボタンで射撃をトリガー
3. 以下を確認：
   - ✓ 射撃アニメーションが再生される
   - ✓ 弾が発射される
   - ✓ 銃声が鳴る
   - ✓ アニメーション終了後、元のステート（IdleまたはWalk）に戻る

## トラブルシューティング

### アニメーションが再生されない
- Animator Controllerが正しくアタッチされているか確認
- Triggerパラメータ名が一致しているか確認（`Shoot`）
- Transitionの設定を確認（Has Exit Timeなど）

### ネットワーク同期されない
- `NetworkMecanimAnimator` コンポーネントがアタッチされているか確認
- Fusionのネットワーク設定を確認
- StateAuthorityが正しく設定されているか確認

### アニメーションがループする
- アニメーションクリップの `Loop Time` を `OFF` に設定
- Shoot → Idle のトランジションが正しく設定されているか確認

### 弾が発射されるがアニメーションが再生されない
- `_animator` または `_networkAnimator` が正しく取得できているか確認
- Animator ControllerにShootトリガーが存在するか確認
- コンソールでエラーメッセージを確認

## 参考

- 歩きアニメーションと同様の方法で統合
- Speedパラメータ（float）は移動速度に応じて変化
- Shootトリガー（trigger）は射撃時に1回だけ発火
